# 🎨 Дизайн-гайд

Цель — ощущение «премиального продукта», а не поделки. Всё подчиняется
нескольким неизменным правилам.

## 1. Палитра эмодзи (единая)

Все эмодзи берутся **только** из `utils/emoji.py`. Никогда не пишем эмодзи
прямо в хендлерах.

| Контекст | Эмодзи |
|---|---|
| Любовь/пара | ❤️ 💑 ✨ 🔥 💌 |
| Навигация | ◀️ ▶️ 🏠 ⚙️ ✅ ❌ ➕ ✏️ |
| Модули | 🔔 🛒 💳 🌤️ 📅 🎁 🎮 🏆 📊 |
| Настроение 1–5 | 😞 😕 😐 🙂 😍 |
| Категории трат | 🍕 🚕 🏠 💊 🎬 🎁 ✈️ 🧾 |
| Прогресс/уровни | 🌱 🌿 🌳 💎 👑 🌟 🚀 🌈 |

## 2. Шрифты

- **Inter** (рекомендуется) — положите `Inter-Regular.ttf` и `Inter-Bold.ttf`
  в `assets/fonts/`. Фолбэк — DejaVu Sans (идёт с matplotlib).
- Заголовки — bold 40–64px, цифры — bold 56–120px, подписи — regular 24–30px.

## 3. Цвета карточек (тёмная тема)

| Роль | RGB |
|---|---|
| Фон | `#181C24` |
| Карточка | `#242A36` |
| Акцент (розовый) | `#FF5E83` |

Карточки тёмные → читаются и на светлом, и на тёмном фоне Telegram.

## 4. Кнопки

- **Главное меню** — ReplyKeyboard, **2 кнопки в ряд, до 8 кнопок**.
- **Внутри модулей** — InlineKeyboard, 2–3 кнопки в ряд, со стилями Bot API 9.x:
  - `style="primary"` — основное действие
  - `style="success"` — подтверждение
  - `style="danger"` — отмена/удаление

## 5. Приёмы

- **Edit-in-place**: один экран-сообщение, меняем через `edit_message_text`.
- **Прогресс-бары**: `▰▰▰▰▱▱▱▱ 50%` (функция `progress_bar`).
- **Загрузка**: `⏳ Считаю...` → результат (или `answer_chat_action("upload_photo")`).
- **Персонализация**: имена, эмодзи под контекст, плюрализация («день/дня/дней»).
- **Моноширинный** для кодов/таблиц: `<code>...</code>`.

## 6. Примеры экранов (текстом)

**Главное меню (ReplyKeyboard):**
```
┌─────────────┬─────────────┐
│ 🔔 Напоминания │ 🛒 Покупки  │
├─────────────┼─────────────┤
│ 💳 Бюджет    │ 🌤️ Настроение │
├─────────────┼─────────────┤
│ 📅 Даты     │ 💌 Спасибо   │
├─────────────┼─────────────┤
│ 🔥 Романтика │ 📊 Статистика │
└─────────────┴─────────────┘
```

**Опрос настроения:**
```
🌤️ Как твоё настроение?
[😞 1] [😕 2] [😐 3] [🙂 4] [😍 5]
[❌ Пропустить]
```

**Создание напоминания:**
```

⏰ Когда? ДД.ММ ЧЧ:ММ
> 14.02 21:00

🔁 Как часто?
[🔂 Один раз] [🔁 Ежедневно] [🗓️ Еженедельно]

👥 Кого уведомлять?
[👥 Обоим] [🙋 Только мне]
```

**Карточка статистики (PNG 1080×1350):** имя пары, «N дней вместе», два
