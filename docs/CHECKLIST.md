# ✅ Чек-лист развития

## Первая неделя (запустить MVP для себя)

- [ ] Завести бота у @BotFather, вписать токен в `.env`.
- [ ] Поднять локально на SQLite (`python -m main`) и пройти путь: создать пару,
      пригласить партнёра по коду.
- [ ] Проверить ядро: напоминание (одноразовое + ежедневное), покупку, трату,
      отметку настроения, благодарность.
- [ ] Сгенерировать карточку статистики и профиля — проверить читаемость шрифтов.
- [ ] Настроить `assets/fonts/Inter-*.ttf` для премиального вида.
- [ ] Включить Redis и PostgreSQL через Docker, прогнать `alembic upgrade head`.

## Первый месяц (привести к «прод»-виду)

- [ ] Деплой на VPS (Docker), настроить webhook или long-polling + systemd.
- [ ] Подключить бэкапы (`--profile backup`) и проверить восстановление.
- [ ] Добить модули-заглушки: капсулы (FSM), календарь месяца, PNG-отчёт благодарностей.
- [ ] Персонализировать викторину (вопросы из данных партнёра).
- [ ] Добавить тесты на репозитории и сервисы (pytest + aiosqlite).
- [ ] Продумать i18n: вынести все строки в `utils/texts.py`, добавить английский.
