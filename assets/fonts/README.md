# Шрифты для карточек

Положите сюда TTF-файлы, чтобы карточки выглядели премиально:

- `Inter-Regular.ttf` — основной текст
- `Inter-Bold.ttf` — заголовки и цифры

Без них код автоматически использует **DejaVu Sans** (поставляется
вместе с matplotlib), так что всё работает «из коробки».

Рекомендация: скачайте Inter с https://rsms.me/inter/ (бесплатно, OFL)
и переименуйте файлы, как указано выше.
